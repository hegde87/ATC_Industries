# ATC Industries V8.8 — Mobile Optimized

Based on approved V8.7. Changes: responsive, accessible mobile menu with collapsible Company and Capabilities submenus; touch-friendly controls; mobile-friendly homepage hero and CTA layout; stacked cards, forms and leadership images; responsive slideshow; optimized WebP photography for faster loading; retained desktop styling and approved assets. No backend changes.

## Preview locally
In PowerShell, change to this extracted folder and run `python -m http.server 8000`. Open `http://localhost:8000` and `http://localhost:8000/leadership.html`.

Test on mobile, tablet, and desktop in Chrome DevTools device mode; also test on a real phone. Form submissions currently open an email client and are not backed by a server. Confirm approval of generated team composite before publishing.
