# ATC Industries — Version 4 (Primera-inspired)

This is an **original** website design inspired by the industrial visual direction of primera-inc.com. No Primera imagery, code, branding, text, or proprietary assets were copied.

## Run locally
Extract the ZIP. Open a PowerShell terminal in the extracted folder and run:

```powershell
python -m http.server 8000
```

Visit http://localhost:8000/index.html

## Pages
Home, Company, Mission & Vision, Leadership, Why ATC, Capabilities, Products, Product Details, Quality, Facilities, Become a Partner, Contact / RFQ.

## Highlights
- Dark transparent navigation, dropdowns, full-width image banners and lime/teal industrial palette
- Original ATC imagery and logo from the presentation
- Quality process and manufacturing workflow sections
- Contact details and quotation form; map locations in Facilities/Contact
- Responsive mobile navigation
